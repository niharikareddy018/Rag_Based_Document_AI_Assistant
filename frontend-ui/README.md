# Frontend UI (React + Tailwind + Vite)

This is the DocLens AI client-side user interface.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start development server on port 3000
npm run dev

# 3. Build production bundle
npm run build
```

## Features
- Document-grounded chat interface with real-time text extraction (PDF, DOCX, TXT, MD)
- Zero asterisk/star clean plain text formatting
- Document history management and counter pill
- Dark and light screen mode
- Direct integration with Spring Boot Vector Service (`http://localhost:8086`) and Ollama
